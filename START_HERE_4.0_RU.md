# GENESIS 4.0 — быстрый старт

## Самый быстрый способ
Открой `pwa/index.html` в браузере. Для сохранения данных используй один и тот же браузер и профиль. Для офлайн-установки и Service Worker нужен HTTPS или localhost.

## iPhone
Размести содержимое папки `iphone/` на приватном HTTPS-хостинге, открой ссылку в Safari → «Поделиться» → «На экран Домой». Само размещение не выполняется этим архивом.

## Что попробовать
1. Заполни девять миров и Personal Model.
2. Создай цели, проекты и действия.
3. Добавь личные записи в Memory.
4. Открой ORACLE: локальный режим ищет по твоим записям и собирает контекст; это не подключённая генеративная модель.
5. Открой Simulation и сравни варианты через Decision Lab.
6. Регулярно делай зашифрованную резервную копию и храни её отдельно.

## Сервер
В `server/` лежит исходный код частного серверного ядра. Запускать его следует только после настройки окружения по `SERVER-START-RU.md` и прохождения release gate в `server/docs/RELEASE_STATUS.md`. Не выставляй его в публичный интернет в текущем состоянии.
