GENESIS 4.0 — ПУБЛИКАЦИЯ НА CLOUDFLARE PAGES С IPHONE

ВАЖНО: папка site/ — готовая статическая PWA. Серверное ядро в source/server/ не нужно для первого запуска и не должно публиковаться вместе с сайтом.

1. Открой Safari и войди в Cloudflare: https://dash.cloudflare.com/
2. В меню Workers & Pages выбери Create application → Pages → Upload assets (Direct Upload).
3. Создай проект с именем genesis-private (или другим свободным именем).
4. На шаге загрузки выбери ZIP «GENESIS_4.0_IPHONE_UPLOAD.zip» из приложения «Файлы». Если интерфейс предлагает загрузить папку, сначала распакуй ZIP и выбери именно содержимое папки site/.
5. Нажми Deploy. Дождись адреса вида https://<project>.pages.dev.
6. Открой полученный адрес в Safari на iPhone. Поделиться → На экран Домой → Добавить.

Не загружай папку source/ на Pages. Она содержит исходный код серверного ядра, которое не настроено для публичного запуска.

ДАННЫЕ И ПРИВАТНОСТЬ
- Данные GENESIS хранятся локально в браузере этого устройства; серверу они не отправляются.
- Установка на экран «Домой» не синхронизирует данные с другими устройствами.
- Делай зашифрованный экспорт в Settings и храни файл и пароль отдельно.
- Сам адрес сайта не является паролем. На сайте нет персонального аккаунта и серверной авторизации.
- Не вводи в локальную PWA данные, которые не хочешь хранить в браузере устройства.

Если мобильный Cloudflare интерфейс не принимает ZIP, не публикуй проект через случайные сторонние сервисы. Можно выполнить загрузку через браузер в режиме «Версия для ПК» либо использовать компьютер позже.
