# GENESIS 5.0 — Telegram Mini App Update

Дата: 04.11.2026

## Что обновлено

- Telegram Mini App: переработан экран безопасного входа с анимированным ядром, состояниями ошибки и повторным подключением.
- Telegram WebApp SDK: запуск и расширение Mini App, оформление верхней панели, мягкая тактильная обратная связь.
- Основная навигация: подключены нативная кнопка BackButton Telegram и haptic feedback при переключении разделов.
- iPhone: учтены safe-area отступы и динамическая высота viewport; масштабирование страницы пользователем не заблокировано.
- Telegram-бот: входящие текстовые сообщения больше не вызывают платный AI API. Запрос сохраняется транзакционно в личной истории ORACLE владельца, бот возвращает кнопку открытия Mini App.
- ORACLE: ручной процесс обмена с ChatGPT остаётся основным — скопировать запрос, вставить ответ и сохранить его в истории. Автоматическая передача личного контекста не включается.

## Проверки

- TypeScript: npm run typecheck — PASS.
