# GENESIS 4.0 — PRIVATE PREVIEW

Дата сборки: 2026-11-03

## Что входит в комплект

- **Universe 4.0 PWA** — единая локальная оболочка девяти миров, целей, проектов, действий, памяти, решений, временной линии и ORACLE workspace.
- **ORACLE continuity** — локальная история нескольких диалогов, лексический поиск по пользовательским записям, прозрачный контекстный пакет. Это не генеративная модель и не подменяет серверный ORACLE.
- **Cognitive Decision Lab** — новый интерактивный инструмент сравнения вариантов по критериям и весам пользователя. Результат — арифметическая модель пользовательских оценок, не предсказание.
- **Private server core** — Next.js/Prisma/PostgreSQL/pgvector исходный код с API профиля, девяти миров, целей, проектов, памяти, разговоров, решений, экспериментов, timeline, экспорта/импорта, ORACLE provider router, Ollama adapter, cost ledger, context policy, ограниченным MCP stdio bridge и тестами.
- **iPhone PWA** — отдельная совместимая папка `iphone/`; установка через Safari после размещения на HTTPS-хостинге.
- Архитектура, инструкции запуска, тесты и handoff.

## Реально проверено в этой сборке

- ZIP integrity.
- JavaScript syntax: inline PWA, `storage.js`, `sw.js`.
- Local ORACLE contract tests: 4/4.
- Server unit/contract tests: результат записан в `VERIFICATION_4.0.txt`.
- Service worker ограничен статической оболочкой; API, авторизованные и динамические ответы не кэшируются. Удаляются только кэши с префиксом GENESIS.

## Границы и честный статус

Это **частный интегрированный preview**, а не подтверждённый production deployment.

- PWA по-прежнему local-first и не синхронизируется автоматически с сервером или между устройствами.
- Локальное хранилище браузера не зашифровано на диске. AES-GCM защищает экспортируемую резервную копию, а не данные в браузере.
- Локальный ORACLE не вызывает LLM; серверное AI-ядро требует отдельной настройки PostgreSQL/pgvector, секретов и провайдера.
- Не включены удалённые write-agents, голос, автономные внешние действия и облачный sync.
- Полный Next.js typecheck/build, Prisma validation/migration на реальном PostgreSQL, browser/iOS Safari E2E, restore drill и security review не подтверждены в этой среде.
- Встроенная серверная регистрация/аутентификация и rate-limit механизмы должны пройти инфраструктурную проверку перед приватным сетевым запуском.
- Никакие секреты, API-ключи, пользовательские данные не добавлялись; ничего не публиковалось и не развёртывалось.

## Запуск

### Локальная PWA

Открой `pwa/index.html` для быстрого ознакомления. Для полноценной установки PWA и Service Worker нужен HTTPS или localhost. На iPhone используй папку `iphone/` и добавь сайт на экран «Домой» через Safari.

### Серверное ядро

Смотри `SERVER-START-RU.md` и `server/README.md`. Не публикуй сервер в открытый интернет до прохождения release gate из `server/docs/RELEASE_STATUS.md` и `server/docs/GENESIS_SECURITY_AND_RELEASE_GATE_0.2.md`.

## Принцип управления

AI расширяет возможности. Человек принимает решения. Любое подключение внешнего AI, синхронизации, удалённых инструментов или действий требует явного выбора владельца.
