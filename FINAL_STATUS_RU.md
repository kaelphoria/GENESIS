# GENESIS 4.0 — финальная сборка для первого использования

## Что готово
- Universe PWA для iPhone, адаптивная оболочка, девять миров.
- Personal Model, цели, проекты, действия, память, решения, timeline.
- ORACLE local workspace: многосессионная история, локальный поиск по пользовательской памяти, прозрачная сборка контекста и локальная рефлексия.
- Cognitive Decision Lab: взвешенное сравнение вариантов по введённым пользователем критериям.
- IndexedDB snapshot durability layer, экспорт/импорт резервных копий, зашифрованный экспорт AES-GCM.
- Service worker: кэширует только статическую оболочку; API, авторизованные и динамические запросы не кэширует.
- Отдельное серверное ядро Next.js/Prisma/PostgreSQL/pgvector в source/server/.

## Повторная проверка в текущей среде
- ZIP исходной сборки распакован и проверен.
- Inline JavaScript PWA, storage.js и sw.js: синтаксическая проверка Node.js пройдена.
- Полный набор автоматических тестов: 168/168 PASS.
- Отдельно: серверные тесты 160/160 PASS; локальные ORACLE 4/4 PASS; Decision Lab 4/4 PASS.
- Контрольная сумма index.html совпадает с предыдущим Cloudflare upload build.

## Что нельзя честно назвать завершённым
- В этой среде не выполнены npm ci, Next.js production build/typecheck и Prisma validation с реальной БД.
- Нет настроенного PostgreSQL/pgvector, AI provider или серверных секретов.
- Нет реального iPhone Safari E2E и публичного деплоя; URL pages.dev ещё не создан.
- ORACLE в PWA — не подключённая LLM: он локально ищет и формирует контекст, а для генеративных ответов этот контекст можно скопировать во внешнюю модель. Серверный ORACLE требует отдельного безопасного развёртывания.
- PWA local-first: нет автоматической синхронизации между устройствами. Браузерное хранилище не зашифровано на диске; AES-GCM защищает резервный экспорт.

## Пакеты
- site/: содержимое для Cloudflare Pages.
- source/server/: отдельное серверное ядро, не для прямой публикации на Pages.
- GENESIS_4.0_IPHONE_UPLOAD.zip: ZIP с файлами сайта в корне для загрузки в Pages.
